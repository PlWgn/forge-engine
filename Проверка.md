# Проверка Forge 1.1.0

Проверено локально 3 октября 2026 на macOS arm64, AppleClang 21, CPython 3.14.3.

- CMake Release: успешная компиляция C++-движка.
- `python tests/integration.py build/bin/forge`: все 17 интеграционных проверок прошли. Помимо базовых JSON/путей/физики/traceback/упаковки проверяются вложенное создание 121 Behavior, однократное уничтожение, spawn из on_destroy, изоляция старой сцены, пауза и подписки, UI-ввод/модальность/клавиатура/resize/очистка, метрики и перенос текста, версии сохранений, миграции, повреждения, backup, autosave, сохраняемые настройки, аудиоканалы и автоматическое чтение.
- Откат hot reload проверен отдельно: настройки, sys.path/sys.modules, прежние объекты и импортированный helper, громкости, существующие голоса, отмена новых голосов и persistent-подписок. После ошибки исправленная сцена успешно запускается. Проверяется контекст прежних настроек в on_destroy.
- `python tests/graphics.py build/bin/forge`: все 4 графические проверки прошли. Проверяются 2D/3D/UI, реальное аудиоустройство, UI в окнах 640×480, 1280×720 и 1920×1080, восстановление после ошибки GLSL, откат подготовленного шейдера при отсутствующей текстуре новой сцены. Последний тест сравнивает кадры до и после неудачной загрузки побайтно и проверяет применение нового шейдера после исправления.
- Новые UI/слоты успешно запущены с графическим окном в отдельной копии самостоятельной сборки, из `/tmp`, с неверными PYTHONHOME/PYTHONPATH. CPython использует комплектный runtime; SaveManager записывает и читает проверенный слот.
- `dist/Game-macOS-1.1.0/Game`: готовая самостоятельная сборка. Финальный пакет успешно запускается headless из другой рабочей папки. Manifest содержит версию 1.1.0 из C++/CMake; проверены SHA-256 всех 705 файлов, включая START.txt и новые модули. Интеграционный тест также проверяет совпадение manifest с forge.__version__, лицензии и независимость от установленного Python.
- Снимки реальных OpenGL-кадров окончательных UI-модулей просмотрены: `artifacts/ui.png`, `artifacts/ui-settings.png`. Размер исходного Retina-кадра — 2560×1440.

Windows: Win32/Unicode-код, miniaudio, OpenGL и workflow macOS/Windows подготовлены. Локальная компиляция и запуск Windows не выполнялись: на этом Mac нет Windows toolchain/окружения. Запустите `.github/workflows/build.yml` либо команды из Инструкция.md на Windows для подтверждения платформы.

Откат распространяется на управляемое состояние движка. Произвольные записи Python в файлы, внешние сервисы, сторонние Python-объекты и уже прошедшее время воспроизведения не являются частью транзакции. Полные границы, API и примеры описаны в Инструкция.md.
