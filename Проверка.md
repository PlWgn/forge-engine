# Проверка Forge 2.0.0

Дата: 4 октября 2026. Локально: macOS arm64, Apple Clang, CMake 3.31.6, CPython 3.14.3.

- C++ Release собран с Assimp 6.0.5 и Dear ImGui 1.91.9b; новые C++ подсистемы разделены на assets/model/features/platform/render/audio.
- CTest: 4/4 набора прошли — numeric, packager_paths (4 проверки), integration (31 тест), features (11 тестов). Проверены реальные публичные API в embedded CPython, не только имитации модулей.
- Graphics: прежние 6 тестов и новые 6 прошли на настоящем OpenGL. Новые проверки: UV-пиксели, batching 100 sprites + 200 glyphs, камеры/FBO, GPU skinning, реальные изменения теней/postprocess, GLSL uniforms, редактор и восстановление window/vsync после отказа reload.
- Persistence: при отказе кандидата не меняются native save, SaveManager slot и deferred файл; новые сырые asset handles освобождаются, input/dt восстанавливаются. Повреждённая внешняя текстура OBJ отклоняется до commit; кадр прежней сцены совпадает побайтно. run загружает будущие ресурсы по требованию, validate/build выполняют полную проверку. После исправления файла движок продолжает работу.
- Ресурсы: фоновые handles/preload/bytes, pin/LRU и отказ по memory budget; glTF с одной костью/анимацией и FBX fixture из Assimp. Позы и кадры анимации сравниваются, большие конечные времена не переполняют расчёт цикла.
- Audio: silent PCM и реальное desktop-устройство; pan/spatial, low/highpass/delay, streaming, voice limits, ducking, subtitles pause/resume/stop.
- Новая сцена advanced.json запущена headless и с окном, кадр просмотрен: artifacts/forge2.png. Видны основной мир, независимая камера, источники света и тени.
- Самостоятельная папка dist/Game-macOS-2.0.0 содержит private Python и manifest 2.0.0. Проверены SHA-256 файлов; запуск advanced.json из /tmp с неверными PYTHONHOME/PYTHONPATH выполнен успешно.
- .app проверена интеграционным тестом: Info.plist, ICNS, Resources/runtime, manifest и codesign --verify --deep --strict. Запуск из /tmp с неверным внешним Python пишет сохранения и лог в пользовательский корень. Готовое локальное приложение: dist/Forge-2.0.0.app.

Developer ID/notarization команды реализованы, но настоящая публикационная подпись и отправка Apple не выполнены: сертификат и профиль не предоставлены. Локальная подпись ad-hoc. Windows собирается отдельным CI job; локальная компиляция/выполнение на Windows в этой сессии не выполнялись.

Полная карта функций: docs/FORGE_2.md. Ограничения: раздел 18 Инструкция.md. Приведённые локальные build/dist/.tools не входят в Git и не появляются автоматически в новом checkout.

# Проверка Forge 1.2.1

Проверено локально 3 октября 2026 на macOS arm64, AppleClang 21, CPython 3.14.3. Это отчёт о локально созданных артефактах: папки build, dist, .tools и загруженные библиотеки не входят в Git и отсутствуют в чистой копии репозитория.

- Чистая временная копия содержала только отслеживаемые файлы, без build/.tools/dist; в vendor были только README и lock. Команды из README создали venv, установили CMake, загрузили проверенные по checksum библиотеки, собрали движок и успешно выполнили validate/dev headless. Это отдельная проверка установки с нуля на macOS.
- Совместимость с указанной копией `game_tests/fnaf`: новый runtime успешно выполнил validate; её контент запущен в отдельной временной копии на 20 headless-кадров. Исходники встроенной копии движка в fnaf при этом не менялись.
- CMake Release: успешная компиляция C++-движка.
- `python tests/integration.py build/bin/forge`: все 26 интеграционных проверок прошли. Помимо базовых JSON/путей/физики/traceback/упаковки проверяются вложенное создание 121 Behavior, однократное уничтожение, spawn из on_destroy, изоляция старой сцены, пауза и подписки, UI-ввод/модальность/клавиатура/resize/очистка, метрики и перенос текста, версии сохранений, миграции, повреждения, backup, autosave, сохраняемые настройки, аудиоканалы и автоматическое чтение.
- Новые регрессии: пять успешных reload не изменяют список sys.path и не дублируют пути; повторяющиеся python_paths объединяются. При смене modules/scripts/scenes/python_paths старые каталоги удаляются из поиска, старые модули и namespace-пакеты больше не импортируются, сторонний путь сохраняется. Пакет из неизменённого дополнительного пути остаётся в кеше. После неудачного перехода каталогов прежние пути восстанавливаются, а следующая успешная смена каталога не оставляет путей отменённой сцены.
- Общий валидатор JSON и Python проверен на переполнении float, неверных векторах/типах, mass/font_size, RGBA/clip, prefab, scripts и ресурсах. Некорректный spawn не вставляет объект в мир. Отдельно проверены Python build(), NaN/Infinity и атомарность числовых setter/move/impulse и камеры.
- Откат hot reload проверен отдельно: настройки, sys.path/sys.modules, прежние объекты и импортированный helper, громкости, существующие голоса, отмена новых голосов и persistent-подписок. После ошибки исправленная сцена успешно запускается. Проверяется контекст прежних настроек в on_destroy.
- Локализация: числовые формы для ru/en/ar/pl/cs/fr/ja/cy/sl/pt-PT (включая десятичные и большие целые), подстановки и буквальные скобки, региональные каталоги, fallback с грамматикой поставившего перевод языка, предупреждение об отсутствующем ключе один раз, ошибки словарей и совместимость старой конфигурации. Проверены реактивные Label/Button/Entity/Journal, реплики и сохранения, восстановление предпочтения после перезапуска, повреждённая настройка и отказ от записи при неудачной инициализации. Hot reload возвращает прежние словари, язык, revision и предпочтение; старый teardown получает прежний контекст локализации. `init` переносит словари и Unicode notice.
- `python tests/graphics.py build/bin/forge`: все 5 графических проверки прошли. Проверяются 2D/3D/UI, реальное аудиоустройство, переключение языка в том же окне со сравнением кадров, UI в окнах 640×480, 1280×720 и 1920×1080, восстановление после ошибки GLSL, откат подготовленного шейдера при отсутствующей текстуре новой сцены. Последний тест сравнивает кадры до и после неудачной загрузки побайтно и проверяет применение нового шейдера после исправления.
- Локализованный UI, переключение русского/английского, настройки и журнал успешно запущены с графическим окном в отдельной копии самостоятельной сборки, из `/tmp`, с неверными PYTHONHOME/PYTHONPATH. CPython использует комплектный runtime; SaveManager записывает и читает проверенный слот.
- `dist/Game-macOS-1.2.1/Game`: готовая самостоятельная сборка. Финальный пакет успешно запускается headless из другой рабочей папки. Manifest содержит версию 1.2.1 из C++/CMake; проверены SHA-256 всех 708 файлов, включая START.txt, словари переводов и Unicode notice. Интеграционный тест также проверяет совпадение manifest с forge.__version__, лицензии и независимость от установленного Python.
- Снимки реальных OpenGL-кадров окончательных UI-модулей просмотрены: `artifacts/ui.png`, `artifacts/ui-settings.png`, `artifacts/ui-en.png`. Размер исходного Retina-кадра — 2560×1440.

Windows: Win32/Unicode-код, miniaudio, OpenGL и workflow macOS/Windows подготовлены. Локальная компиляция и запуск Windows не выполнялись: на этом Mac нет Windows toolchain/окружения. Запустите `.github/workflows/build.yml` либо команды из Инструкция.md на Windows для подтверждения платформы.

Откат распространяется на управляемое состояние движка. Произвольные записи Python в файлы, внешние сервисы, сторонние Python-объекты и уже прошедшее время воспроизведения не являются частью транзакции. Полные границы, API и примеры описаны в Инструкция.md.
