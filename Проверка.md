# Проверка Forge

Проверено локально 3 октября 2026 на macOS arm64, AppleClang 21, CPython 3.14.3.

- CMake Release: успешная компиляция C++-ядра.
- `python tools/forge.py test`: 10 интеграционных проверок прошли. Проверяются повреждённые ресурсы, JSON и синтаксис Python, пути с кириллицей и переименование групп папок, физика и события, сохранения, переходы сцен, traceback, hot reload, ошибки shutdown и независимая упаковка CPython.
- `python tests/graphics.py build/bin/forge`: 2 графические проверки прошли. Проверяются оба режима OpenGL, текстуры/OBJ/текст, запуск аудиоустройства и восстановление после ошибки компиляции GLSL без закрытия окна.
- C++-модуль `modules/native_example.cpp` подключён через отдельный JSON, скомпилирован и вызван из Python; затем базовая конфигурация восстановлена.
- Контролируемая ошибка runtime сохранила файл/строку traceback и успешно отправила корневой forge.log системному приложению для открытия. Записи `EXPECTED SELF-TEST` в журнале относятся к этой проверке.
- `validate` и запуск headless через developer launcher: успешны.
- `dist/Game-macOS/Game`: самостоятельная сборка, успешно запущена с графическим окном. Во время интеграционных проверок запускается из другой рабочей папки с неверными PYTHONHOME/PYTHONPATH; sys.prefix указывает на поставляемый runtime.
- Manifest сборки: проверены SHA-256 694 файлов. Python runtime и ресурсы поставляются вместе с бинарным файлом.

Снимки реальных OpenGL-кадров: `artifacts/2d.png`, `artifacts/3d.png`.

Windows: исходники, Unicode CLI, Win32-открытие журнала, DLL-упаковка и workflow macOS/Windows подготовлены. Локальная компиляция и запуск Windows не выполнялись: на этом Mac нет Windows toolchain/окружения. Запустите `.github/workflows/build.yml` либо команды из Инструкция.md на Windows для подтверждения платформы.

Инструкция.md описывает реальные возможности и ограничения реализации, включая AABB-физику и отсутствие визуального редактора.
