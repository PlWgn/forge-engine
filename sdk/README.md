# Forge editor API 1

Standard-library Python SDK for any shell. Install from this folder or add it to Python search path; provide a compiled Forge binary (builtin GUI optional). Client/Document speak local JSON-lines; RuntimeClient adapts the same commands inside native edit. No GUI toolkit, network service or game dependency. Source and wheel preserve Forge Attribution License 1.0/NOTICE. SDK modules are outside the engine core list and can be adapted. See the engine docs/PROJECT_API.md for the versioned protocol, format, extensions, conflict handling and examples.
